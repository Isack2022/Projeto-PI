# ☀️ Sistema Solar Interativo

Projeto acadêmico desenvolvido com o objetivo de criar uma experiência **interativa e visual do Sistema Solar**, utilizando animações, efeitos gráficos, sons e páginas individuais para os planetas.

A aplicação permite que o usuário explore diferentes planetas por meio de uma interface visual e interativa, combinando **HTML, CSS, JavaScript e p5.js**.

---

## 🚀 Funcionalidades

- 🌌 Representação visual do Sistema Solar
- 🪐 Páginas individuais para diferentes planetas
- ✨ Animações e efeitos visuais
- 🎨 Elementos gráficos desenvolvidos com p5.js
- 🔊 Reprodução de áudio
- 🖼️ Utilização de imagens e recursos visuais
- 🖱️ Interação do usuário com os elementos da aplicação
- 📱 Interface adaptada para diferentes tamanhos de tela

## 🎯 Objetivo

O projeto foi desenvolvido como uma forma de aplicar conhecimentos de **desenvolvimento web, JavaScript e programação visual**, explorando conceitos de animação, interação com o usuário e manipulação de elementos gráficos.

O uso do **p5.js** possibilitou a criação de elementos visuais e animações que tornam a experiência mais interativa.
